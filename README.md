# Web-Animation-Template

My template repository for creating web animations

A fork of [eniallator/Aurora-Borealis-Art](https://github.com/eniallator/Aurora-Borealis-Art). It's an aurora borealis simulation made as web art, built on the author's web-animation template.

## What's inside

- `index.html`, `index.js` and `init.js`: the page and its startup code.
- `src/`: the animation source.
- `styles.css`: the styles.
- `LICENSE`: the upstream license.

## How to view it

Open `index.html` in a browser (a local static server is the safest option), or see the upstream live page at https://eniallator.github.io/Aurora-Borealis-Art/.
